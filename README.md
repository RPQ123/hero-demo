# 英雄归来 · 单机网页 DEMO

在 GitHub Pages 网站中打开即可游玩，推荐使用桌面版 Chrome 或 Edge，配合鼠标和键盘。

选择英雄、地图和模式后，点击「开始行动」。按 Esc 暂停并释放鼠标。

游戏在玩家自己的浏览器中独立运行；设置、生涯和成就保存在该浏览器的本地存储中，不会跨电脑同步。

这是一个非官方粉丝制作的单机演示项目，与 Blizzard Entertainment 无隶属关系。第三方素材和开源组件的说明见 THIRD_PARTY_NOTICES.txt。

## 部署

仓库 Settings → Pages → Deploy from a branch → main → /(root)。

本目录的 index.html 已包含游戏代码、图片和字体，可直接作为静态网页发布。更新时替换 index.html，并同步 THIRD_PARTY_NOTICES.txt。
